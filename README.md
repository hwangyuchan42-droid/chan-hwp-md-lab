# HWP·HWPX → Markdown 측정실

한글 문서(HWP 5.x·HWPX)를 Markdown으로 변환하는 방식을 비교하기 위한 **시험 도구와 측정 결과**입니다. 현재 코드는 변환 실험기이며, 완성된 변환기가 아닙니다.

## 측정 결과

| 시험 | 관측 결과 |
|---|---|
| 공개 실문서 HWP 1개 | 수정 DLL은 자동 검수에서 표 **197/197개**의 값·좌표·병합·순서를 보존했습니다. 표 밖 본문의 기존 순서 검수 점수는 **607/749개**였습니다. |
| 공개 실문서 HWPX 1개 | 수정 DLL은 표 **5/5개**, 표 밖 본문 **21/29개**가 일치했습니다. |
| 합성 혼합 1,000개 | 고유 원본 4개를 복제한 자료에서 기존 DLL 실험기 4작업자가 kordoc 4작업자 대비 **4.97배**의 처리량을 기록했습니다. 이 자료에는 병합 셀·제목·목록이 없습니다. |
| 공개 실문서 2개 소량 처리 | 같은 세션에서 5회 교차 실행한 중앙값은 **unhwp CLI 0.172초**, **hwp2md 0.086초**, **수정 DLL 0.366초**였습니다. 앞의 두 도구가 이 작업을 더 빨리 마쳤고, 도구별 표·본문 일치 수는 달랐습니다. 표는 수정 DLL이 가장 많이 일치했고, HWPX 본문은 hwp2md가 28/29로 수정 DLL의 21/29보다 많이 일치했습니다. |

## 본문 진단과 화면 대조

두 공개 문서에서 수정 DLL의 기존 검수 불일치 **150개(HWP 142개, HWPX 8개)**를 자체 분류했습니다. 이 150개는 모두 목록 또는 강조 표기 차이였고, 진단의 정규화 기준에서 실제 본문 누락으로 분류된 항목은 **0개**였습니다. 표 밖 최상위 문단의 자동 검수 범위에 해당합니다. [본문 진단](bench/BODY_DIAGNOSIS_2026-11-23.md) · [대응 줄과 순서 보강 검증](bench/BODY_DIAGNOSIS_ADDENDUM_2026-11-23.md)

AI 에이전트가 한/글 2024 화면에서 일부 표본 9/23을 대조했습니다. 확인 범위에서 내용이나 순서가 다른 사례는 관찰되지 않았고 목록 표지의 차이는 기록했습니다. 작성자도 일부 표본을 대조했으며 AI 에이전트의 판정과 불일치 0건으로 보고했습니다. 작성자 대조 건수는 미확정이며 두 대조 모두 표본 범위입니다. 큰 병합 표는 대표 셀과 병합을, 삭제 표는 기본 열람 화면을 확인했습니다.

글상자·각주·머리말의 내용, 목록 계층 보존, 큰 병합 표의 셀 전수 대조, 삭제 표의 ‘최종본’ 보기 전환, 다른 문서는 확인이 남아 있습니다.
