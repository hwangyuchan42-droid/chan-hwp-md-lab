# HWP·HWPX → Markdown 측정실

한글 문서(HWP 5.x·HWPX)를 Markdown으로 변환하는 방식을 비교하기 위한 **시험 도구와 측정 결과**입니다. 현재 코드는 변환 실험기이며, 완성된 변환기가 아닙니다.

## 측정 결과

| 시험 | 관측 결과 |
|---|---|
| 공개 실문서 HWP 1개 | 수정 DLL은 자동 검수에서 표 **197/197개**의 값·좌표·병합·순서를 보존했습니다. 사람의 원본 대조 전입니다. 표 밖 본문은 **607/749개**가 순서대로 일치했고 불일치 원인은 분석 전입니다. |
| 공개 실문서 HWPX 1개 | 수정 DLL은 표 **5/5개**, 표 밖 본문 **21/29개**가 일치했습니다. |
| 합성 혼합 1,000개 | 고유 원본 4개를 복제한 자료에서 기존 DLL 실험기 4작업자가 kordoc 4작업자 대비 **4.97배**의 처리량을 기록했습니다. 이 자료에는 병합 셀·제목·목록이 없습니다. |
| 공개 실문서 2개 소량 처리 | 같은 세션에서 5회 교차 실행한 중앙값은 **unhwp CLI 0.172초**, **hwp2md 0.086초**, **수정 DLL 0.366초**였습니다. 앞의 두 도구가 이 작업을 더 빨리 마쳤고, 도구별 표·본문 일치 수는 달랐습니다. 표는 수정 DLL이 가장 많이 일치했고, HWPX 본문은 hwp2md가 28/29로 수정 DLL의 21/29보다 많이 일치했습니다. |
